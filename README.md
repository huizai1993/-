# WIN运维工具

面向内网运维的 Windows 桌面工具，主要解决设备发现、资产登记、录像下载转码、局域网测速传文件、SSH 与串口调试这类日常重复工作。

- 版本：1.1.25
- 更新时间：2026-11-03
- 运行环境：Windows 10 / 11 x64
- 界面：WPF 深色科技风，全局微软雅黑

## 下载

安装包统一发布在 Releases 页面：

https://github.com/huizai1993/-/releases

推荐下载 `运维工具安装包1.1.25.msi`，双击按向导安装即可。

## 安装说明

1. 运行 MSI，按向导依次选择安装路径、全局工作路径。
2. 程序通过 app.manifest 自动请求管理员权限（需要修改网卡、二层抓包、访问受限目录），UAC 弹窗请选择“是”。
3. 首次使用请进入「设置 - 路径设置」确认全局工作路径，SDK 配置、录像文件、局域网接收文件都存放于该目录。
4. 升级覆盖安装时会自动备份并恢复 `config.json` 与快捷访问配置，不会丢设置。

## 功能概览

### 界面

- 无边框窗口 + 自绘标题栏 + 左侧分组导航，页面切换不打断后台任务
- 标题栏实时显示时间、农历、CPU、内存、硬盘读写、网络上下行、本机详情
- 主界面任务总览：正在执行、已运行最久、已完成记录，支持模块筛选、结果颜色区分、双击查看详情、导出 CSV，跨重启保留最近 1000 条
- 统一深色弹窗体系：消息、输入、表单、轻提示、右键菜单

### 设备

- 设备搜索：全局搜索 / 海康 / 大华 / TP / Ping + 私有协议分栏，搜索前自动检测防火墙并可一键开启
- TP 二层搜索：wpcap 二层抓包，支持 TP 网桥、CPE 及 SDK 摄像头、NVR，多网卡同时广播
- 设备管理资产库、两次搜索结果对比、IP 网段扫描

### 监控设备

- 海康 / 大华 NVR：登录、通道与时间段选择、录像下载任务、转码（支持硬件加速）、多任务排队、实时预览与回放、抓图
- 海康摄像头管理：设备信息、时间同步、SADP 检测、SD 卡状态与容量、预览回放、巡检

### 网络管理

- 局域网测试：iperf3 服务端/客户端（输出中文化）
- 文件传输服务端/客户端：自研 TCP 协议（文件名、大小、数据、CRC32 校验），网络收发与磁盘读写分离（512MB 有界队列），分别统计网速与磁盘速度，显示握手耗时与延迟，同名文件自动加序号，任务结束 1 分钟后自动清理

### SSH 与串口

- SSH 终端：WebView2 内置终端、多会话、主机指纹、连接历史
- SSH 文件传输：SFTP 上传/下载、远程目录浏览，任务登记到主界面任务总览并可跳转
- 串口调试：TCP 串口、COM 串口、交换机 Console 三种模式，命令记事本，Modbus 调试（从机 ID、功能码、寄存器、报文预览）

### 效率工具

- 批量操作：批量重命名文件/文件夹、批量移动文件、批量压缩文件夹
- 文件与应用：文件（数据库，压缩存入 Access）与文件（本地，按分类目录存放）
- 文本文档、命令行操作（CMD / PowerShell / Ping / 端口扫描 / 命令记事本）
- 快捷访问：全局快捷键唤出，支持网站、文件夹、程序、系统功能，图标取系统真实图标
